> 参考文章：[《yt-dlp 从入门到顺手：我把 B 站、YouTube、抖音视频一键下载到本地》](https://zhuanlan.zhihu.com/p/2045080302888939589)

> 存档服务均被拦截），因此无法逐字引用正文。下面的痛点来自该文标题与检索摘要，加上 yt-dlp 社区
> （GitHub Discussions / Reddit / 知乎同类教程评论区）长期反复出现的 15 类问题；每一类都给出了
> GlowDL 的具体解法、代码位置与验证方式，供审查时逐条对照。

## 1. 快速对照表

| # | 现象（用户视角） | 根因 | GlowDL 解法 | 验证方式 |
|---|---|---|---|---|
| 1 | “还要装 Python？还要开终端？” | yt-dlp 是命令行工具 | 打包成 `.app` / `.exe`，全中文 GUI | 双击运行；`scripts/build_*.{sh,ps1}` |
| 2 | `ffmpeg not found`，1080P 只能下到无声视频 | yt-dlp 不内置 ffmpeg，音视频是两条流 | 内置 `imageio-ffmpeg` 二进制，自动定位并传给 yt-dlp | `--diagnose` 第 4 项；`app/core/ffmpeg_tools.py` |
| 3 | YouTube：*Sign in to confirm you're not a bot* | 机房/代理 IP 被风控，需要登录态 | 设置页选择已登录浏览器，直读 Cookie；支持 cookies.txt / JSON | 诊所第 10 项；`app/core/cookies.py` |
| 4 | B 站 1080P+ / 4K 只能下 480P | 高码率需要登录（大会员） | 同一 Cookie 入口 + 画质预设；诊所提示“该视频最高 720P” | 手动选 1080P 下载 |
| 5 | 抖音 / 小红书 一解析就 403、拿不到无水印 | 需要 UA / Referer / Cookie 组合 | 设置页可覆盖 UA、Referer；Cookie 直读；错误卡片给“读取 Cookie”按钮 | `settings_referer` + 重试 |
| 6 | 不知道 `-f 137+140` 是什么意思 | yt-dlp 用 format id 表达流组合 | 中文画质预设 + 「全部格式」表格（编码/帧率/体积/id），双击复制 id | 下载页 → 全部格式 |
| 7 | 下载到一半断网，只能从头再来 | 未保留分片 / 不开续传 | 暂停保留 `.part`，重试走 `continuedl`；内置重试与分片并发 | `pytest tests/test_engine.py::test_cancellation_keeps_partial_file` |
| 8 | 报错一大段英文 traceback，搜不到答案 | yt-dlp 报错偏底层 | 24 条规则翻译成中文，附原因与「一键修复」按钮 | 下载失败卡片 / 诊所 → 报错百科 |
| 9 | 用着用着突然所有站点都失效 | 站点改版，内核过期 | 应用内「检查更新」；打包版从 PyPI 取 wheel 解包热更新 | 设置 → 下载内核 |
| 10 | 速度慢、只能一个一个下 | 单线程串行 | 并发队列（1–6）+ 分片并发 + 可选限速 | 队列页 |
| 11 | 字幕/封面/元数据不会加 | 需要 `--write-subs --embed-thumbnail ...` | 三个勾选框，默认嵌入封面与元数据 | 设置 → 后处理 |
| 12 | 下完找不到文件 | 输出目录记不住 | 历史记录（标题/站点/画质/大小/时间）+ 打开文件夹 | 历史页 |
| 13 | 代理每次都要写环境变量，或代理关了仍报 `Connection refused` | 需要 `--proxy`；系统代理被桌面应用继承 | 网络模式三选一：跟随系统 / 直连 / 自定义代理；代理端口不可达时给出「改为直连并重试」 | 设置 → 网络模式；`app/core/netproxy.py` |
| 14 | Windows 上中文/特殊字符文件名报错 | 非法字符、保留名、路径过长 | 文件名清洗（全角替换非法字符）、模板校验、重名编号 | `pytest tests/test_core.py -k filename` |
| 15 | 播放列表要一条条复制 | 默认 noplaylist | 勾选「按播放列表下载」整体入队 | 下载页 → 播放列表 |

## 2. 报错速查表（软件内「报错百科」的数据源）

GlowDL 会把原始错误用正则匹配到固定 `code`，再渲染中文标题、原因、修复按钮。规则定义在
`app/core/errors.py`，测试在 `tests/test_core.py::test_error_translation`（覆盖 23 条样例）。

| 原始报错关键词 | code | 中文含义 | 一键修复 |
|---|---|---|---|
| `Sign in to confirm ... not a bot` | `bot_check` | 站点要求验证真人 | 读取浏览器 Cookie / 打开登录页 / 重试 |
| `only available for registered users` | `login_required` | 需要登录 | 读取 Cookie / 打开站点登录 |
| `HTTP Error 403` | `forbidden_403` | 请求被拒 | 读取 Cookie / 重试 |
| `HTTP Error 404` | `http_404` | 页面不存在 | 检查链接 |
| `HTTP Error 429` | `rate_limited` | 被限流 | 稍后重试 / 降低并发 |
| `ffmpeg ... not found` / `ffprobe ... not found` | `ffmpeg_missing` | 缺少 ffmpeg | 自动修复 / 运行自检 |
| `Requested format is not available` | `format_unavailable` | 画质不可用 | 改用最佳画质 |
| `Private video` | `private_video` | 私享视频 | 读取 Cookie |
| `not available in your country` | `geo_blocked` | 地区限制 | 配置代理 |
| `premium members only` / `paid` | `membership` | 会员/付费内容 | 仅提示，不绕过 |
| `DRM` / `widevine` | `drm` | DRM 保护 | 仅提示，不绕过 |
| `certificate verify failed` | `ssl_error` | 证书校验失败 | 网络自检 / 代理设置 |
| `nodename nor servname` | `dns_error` | DNS 失败 | 配置代理 / 重试 |
| `Connection reset` / `timed out` | `timeout` | 网络超时 | 重试 / 降低并发 |
| `No space left` | `disk_full` | 磁盘满 | 更换下载目录 |
| `Permission denied` | `permission_denied` | 无写权限 | 更换下载目录 |
| `Postprocessing: ...` | `postprocess_failed` | 后处理失败 | 调整后处理 / 修复 ffmpeg |
| `Unable to extract ...` | `extractor_broken` | 解析器过期 | 更新内核 |
| `Unsupported URL` | `unsupported_url` | 不支持该链接 | 重新解析 |
| `Download cancelled` | `cancelled` | 已取消 | 继续下载 |
| 其它 | `generic` | 未归类失败 | 重试 / 运行自检 |

## 3. 环境自检（问题诊所的 10 项检查）

| 检查 | 失败时会怎样 | 修复动作 |
|---|---|---|
| Python 运行时 | 无法启动（仅源码模式） | 安装 3.10+ |
| 运行平台 | 非 Win/mac 时提示 | 仅支持三大平台 |
| yt-dlp 内核 | 无法解析任何站点 | 安装/更新内核 |
| ffmpeg | 高清无声音、后处理失败 | 自动修复（内置二进制） |
| 下载目录可写 | 下载末尾失败 | 更换目录 |
| 磁盘空间 | 大文件下载中断 | 清理空间 |
| 代理 | 境外站点无法解析 | 检查代理地址/端口 |
| 站点连通性 | B 站/YouTube 不可达 | 配置代理 |
| HTTPS 证书链 | SSL 校验失败（常见于 python.org 安装包） | 内置 certifi + 网络自检 |
| 登录 Cookie | 高清/会员内容失败 | 选择浏览器或导入 cookies.txt |

自检是**并行**执行的（`concurrent.futures`），最慢的网络探测 6 秒超时，因此页面通常 6 秒内出结果。

## 4. 这个问题清单是怎么验证的

- **单测**：`tests/test_core.py` 覆盖错误映射、文件名清洗、预设选择器、设置持久化、历史去重、Cookie 转换。
- **集成**：`tests/test_engine.py` 用本地 `http.server` + ffmpeg 生成的 mp4 走真实 yt-dlp 下载、
  转 MP3、验证取消后 `.part` 保留（对应第 2、7 条）。
- **GUI**：`tests/test_ui.py` 在 offscreen 下渲染媒体卡片、失败卡片、队列进度、历史行与主题切换。
- **截图**：`scripts/preview_ui.py` 不依赖网络，可重复生成 `docs/screenshots/`。

如果审查时发现某条真实报错没有命中规则，只需要在 `RULES` 里加一条 `_rule(...)` 并补一个用例，
UI 与诊所会自动复用。
