# 构建与发布

## 1. 环境要求

| 平台 | 最低版本 | 构建环境 |
|---|---|---|
| macOS | 11.0+ | macOS 13+，Xcode Command Line Tools（`iconutil`/`codesign`/`hdiutil`） |
| Windows | 10 1809+ | Windows 10/11，PowerShell 5.1+ |
| Python | 3.9+（推荐 3.10/3.11） | 64 位 |

PyInstaller **不能跨平台交叉编译**：macOS 产物必须在 macOS 上构建，Windows 产物必须在 Windows 上构建。
仓库已提供 GitHub Actions 双平台矩阵，推送 tag 即可得到两个安装包。

## 2. 一键构建

```bash
# macOS
bash scripts/build_macos.sh

# Windows（PowerShell）
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

脚本依次执行：

1. 创建/复用 `.venv`，安装 `requirements.txt` 与 `pyinstaller`；
2. 运行 `scripts/make_icons.py` 生成 `icon.icns` / `icon.ico` / PNG；
3. `pyinstaller scripts/glowdl.spec` 构建 one-dir 产物；
4. macOS：ad-hoc 签名 + `hdiutil` 打 DMG；Windows：`Compress-Archive` 打 zip。

产物：

```text
dist/GlowDL.app                     # macOS 应用
dist/GlowDL-1.0.0-macOS.dmg         # macOS 安装镜像
dist/GlowDL/GlowDL.exe              # Windows 可执行文件
dist/GlowDL-1.0.0-Windows-x64.zip   # Windows 分发包
```

体积参考：macOS 约 180–240 MB（Qt 框架 + ffmpeg + yt-dlp 全量 extractor），
Windows 约 160–220 MB。`yt_dlp` 的所有站点解析器必须随包分发，因此体积无法压到几十 MB；
如需更小体积，可改为「内置精简内核 + 首次启动时热更新」。

## 3. PyInstaller spec 说明

`scripts/glowdl.spec` 做了四件事：

1. `collect_data_files("imageio_ffmpeg")` —— 把内置 ffmpeg 二进制打进包里；
2. `collect_submodules("yt_dlp")` —— yt-dlp 的解析器是动态发现的，必须显式收集，否则运行时
   会出现 “No suitable extractor”；
3. `datas` 打入 `app/resources`（图标）；
4. macOS 下额外生成 `BUNDLE`，写入 `Info.plist`（HiDPI、最低系统版本、URL scheme 类型）。

若新增资源文件，记得同时更新 spec 的 `datas` 与 `pyproject.toml` 的 `package-data`。

## 4. 签名与分发

### macOS

当前脚本使用 **ad-hoc 签名**（`codesign --sign -`），用户首次打开需要右键 → 打开。
正式分发建议：

```bash
# 需要 Apple Developer ID 证书
codesign --deep --force --options runtime --sign "Developer ID Application: Your Name (TEAMID)" dist/GlowDL.app
xcrun notarytool submit dist/GlowDL-1.0.0-macOS.dmg --keychain-profile "glowdl" --wait
xcrun stapler staple dist/GlowDL-1.0.0-macOS.dmg
```

未公证时，用户看到的是 Gatekeeper 提示，不是病毒告警；README 已写明绕过步骤。

### Windows

未签名 exe 会触发 SmartScreen「未知发布者」。正式分发建议购买代码签名证书：

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a dist\GlowDL\GlowDL.exe
```

## 5. 版本号与更新

- 版本号在 `app/__init__.py::__version__`，同时被 `pyproject.toml` 与 spec 的 `Info.plist` 使用。
- 内核更新与应用版本**解耦**：应用内「检查更新」只更新 yt-dlp 内核（PyPI wheel 解包到
  `%APPDATA%/GlowDL/core/<version>` 或 `~/Library/Application Support/GlowDL/core/<version>`，
  启动时前置到 `sys.path`）。因此不需要为了站点适配重新发版。

## 6. CI（GitHub Actions）

`.github/workflows/build.yml`：

- `macos-14` 与 `windows-latest` 双矩阵；
- 安装依赖 → 跑 `pytest`（GUI 测试用 `QT_QPA_PLATFORM=offscreen`）→ 构建；
- 上传 `dist/*.dmg` 与 `dist/*.zip` 为 artifact；
- `push` 到 `main`、PR、手动触发都会执行；推 `v*` tag 时额外创建 Release（可选）。

首次在 CI 构建时若网络较慢，macOS 拉取 Qt wheel 可能超时；可在 workflow 中配置 pip 镜像：

```yaml
env:
  PIP_INDEX_URL: https://pypi.tuna.tsinghua.edu.cn/simple
```

## 7. 常见构建问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `iconutil: command not found` | 非 macOS 环境 | 正常，`.icns` 只在 macOS 生成 |
| 启动即闪退 | 缺 Qt 插件 / 未收集 yt_dlp 子模块 | 检查 spec 的 `hiddenimports`、Qt 插件目录 |
| 提示 `No module named yt_dlp.extractor.xxx` | 打包时未执行 `collect_submodules` | 重新构建 |
| 下载报 `ffmpeg not found` | 未打入 `imageio_ffmpeg` 数据文件 | 检查 `collect_data_files` 与 `dist/GlowDL/_internal` |
| macOS 首次打开被 Gatekeeper 拦截 | ad-hoc 签名未公证 | 右键 → 打开，或按第 4 节公证 |
| Windows 安全软件误报 | 未签名 one-dir 可执行文件 | 代码签名或加白名单 |
